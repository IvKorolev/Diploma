# Прогнозирование пользовательского поведения на основе истории транзакций с использованием методов глубокого обучения

## Описание проекта

Дипломный проект, посвящённый прогнозированию наиболее вероятной категории покупки пользователя в следующем месяце на основе истории его транзакций с использованием методов машинного и глубокого обучения.

Основное внимание уделяется исследованию последовательностей покупок и оценке влияния их временного порядка на качество прогнозирования.

## Актуальность

История транзакций содержит информацию о покупательских предпочтениях и поведении пользователей. Методы глубокого обучения позволяют моделировать зависимости между последовательными событиями и потенциально повышать качество прогнозирования будущих покупок.

## Проблема исследования

Недостаточная изученность эффективности методов глубокого обучения, учитывающих последовательность транзакций, для прогнозирования категорий покупок по сравнению с классическими подходами.

## Цель проекта

Разработать и экспериментально оценить подход к прогнозированию наиболее вероятной категории покупки пользователя в следующем месяце на основе истории его транзакций.

## Основные задачи

- Изучить существующие методы прогнозирования покупательского поведения.
- Выбрать источник транзакционных данных и выполнить их предварительную обработку.
- Сформировать последовательности транзакций для обучения и оценки моделей.
- Реализовать базовые подходы.
- Исследовать применение LSTM, Transformer или других выбранных моделей для моделирования последовательностей.
- Сравнить качество моделей и оценить влияние учёта последовательности транзакций на результаты прогнозирования.

## Технологический стек

- **Python** — основной язык программирования.
- **pandas, NumPy** — обработка и анализ данных.
- **scikit-learn** — классические модели машинного обучения и оценка качества.
- **PyTorch** — реализация моделей глубокого обучения.
- **Matplotlib, Seaborn** — визуализация результатов экспериментов.
- **Jupyter Notebook** — исследовательский анализ и эксперименты.

## Ожидаемые результаты

- Подготовленный набор данных для задачи прогнозирования.
- Реализованные и обученные модели различных классов.
- Сравнение качества прогнозирования на единой экспериментальной основе.
- Оценка преимуществ и ограничений последовательного моделирования.
- Выводы о применимости методов глубокого обучения к прогнозированию категорий покупок.

## Практическая значимость

Результаты исследования потенциально могут применяться для персонализации рекомендаций, анализа покупательских предпочтений и поддержки решений в области маркетинга.

## Метрики оценки

Для сравнения моделей предполагается использовать:

- **Accuracy** — долю правильных прогнозов.
- **Macro-F1** — качество классификации с учётом вклада отдельных категорий.

Окончательный набор метрик будет определён с учётом характеристик выбранных данных и постановки задачи.
